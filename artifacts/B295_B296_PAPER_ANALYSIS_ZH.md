# 两篇 TAES 2026 原文分析与尾部适配

本文件区分原文设计、我们的适配和仍需实验验证的结论。没有复现两篇完整网络，也没有本地雷达 Pd 增益结果。原文 PDF 不随公开代码包分发。

## 1. Hybrid Graph Node Learning Network for Marine Radar Target Detection

Zhu 等，IEEE TAES，2026，62：17905–17920。DOI：10.1109/TAES.2026.3732287。原文注明 2026 年 9 月 8 日出版。

### 原文解决什么问题

原文将多个距离单元中的连续雷达信号切成片段，经 Doppler 变换形成节点，再建立跨节点的时空关系。它不是对单张时频图做普通分类的 ResNet 模块。主要问题是：粗糙图连接会把不相关杂波接到目标节点；传统图传播又可能把少数目标节点的特征平滑掉。

完整网络包含三部分：

1. CFGC 粗到细图构建。先结合近邻连接与时空邻接，通过结构熵确定时间连接跨度，再以稀疏、低秩和图平滑约束细化邻接矩阵。式(7)–(11)、(30)–(36)涉及结构优化及近端更新。
2. GSDTRL 图频谱解耦目标表征。式(14)进行两层线性投影；式(15)–(17)讨论图谱滤波及一阶近似；式(18)–(20)对两支输出计算节点相关权重，进行频带自适应融合。
3. TESCRL 杂波时序演化表征。式(22)–(26)包含注意力、非线性映射与图卷积。最后与 GSDTRL 的输出融合，做节点检测。

原文实验使用长度256的非重叠信号段，目标节点与杂波节点约为1:10或1:11，采用类别加权交叉熵。主要消融工作点为 Pfa=1e-3。其图结构、节点标签及类别不平衡均不同于我们平衡的单 CUT IQ512 二分类，不能直接搬运其损失和 Pd 数字。

### 选择的部分及必要修改

本次只借鉴 **GSDTRL 的双分支表征和频带自适应融合**，不移植整个图网络。

- 接入位置：冻结 ADN 的 Layer4 输出之后。完整7×7深层图仍按原样进入原 GAP 与原 FC；新分支另做4×4平均池化，得到16个512维节点。
- 节点代表同一个样本的深层特征区域，不代表额外的距离单元或连续观测。没有跨 batch 构图，因此一个样本的推理结果不依赖一起送入 GPU 的其他样本。
- 两层投影得到16×64特征，构造非负余弦4近邻图，取对称连接并加入自环。令 S=D^(-1/2)AD^(-1/2)。
- 显式构造低通 L(X)=(X+SX)/2、高通 H(X)=(X-SX)/2。它们之和等于 X，在归一化图拉普拉斯特征值 λ 上对应1-λ/2与λ/2两种不同响应。
- 原文式(17)给出的两支采用相同的一阶图算子，靠不同参数和后续约束学习。本次采用上述显式互补算子，是适配选择，不宣称是作者的实际代码或对原文的修复。
- 参考式(18)–(20)计算每节点的高低通权重，再做节点注意力聚合，输出一个有界的检测分数修正量。
- 不采用式(21)要求的目标/杂波节点标签：我们的类别标签属于整个 IQ 样本，无法证明其中每个深层区域都是目标或杂波。
- 训练目标沿用 CE，新增52,626个参数，原 TFSE、ADN、8个原生 SimAM、GAP、FC全部冻结。

这里的“图高频”是深层特征相对于图连接的变化，不能直接解释为高 Doppler、高速目标，也不能认定所有目标一定在高频支路。

### 本路的研究假设

TFSE 已提供有效的时频显示表征。全局平均池化可能未充分利用深层区域之间的差异；图频带细化尝试从局部一致性与局部差异中补充判别线索。该假设是否成立，要看固定基线下的配对 Pd、D80/D90 与独立 H0 审计，不能仅由图滤波结构推断。

## 2. Multidomain Features Guided Supervised Contrastive Learning for Maritime Target Detection

Wang 等，IEEE TAES，2026，62：8386–8400。DOI：10.1109/TAES.2026.3678591。原文注明 2026 年3月30日出版。

### 原文解决什么问题

完整 MDFG_SCL 不是一个新的2D ResNet18注意力层。它用1D ResNet50提取幅度序列的深层特征，通过两层投影头得到128维表示；另一支提取物理可解释的浅层特征，再将两类表征对齐并进行监督对比学习。

原文浅层向量包含7项：RAA、RDPH、RVE、时频脊积分、连通区域数量、最大连通区域大小和 WFR。式(1)–(3)中的 WFR 为小波近似能量比 WAER 除以小波熵 WE；WE 的式(2)对细节层能量比例求熵。图示使用三级小波分解。

式(5)–(7)采用 Gini 指标进行特征加权；式(8)为两层投影；式(9)–(10)为浅深特征的归一化映射和双向匹配；式(11)–(12)引入监督对比损失。原文训练时优化表征，测试阶段冻结模块并使用线性分类器。

作者采用 batch512、100个epoch、SGD、学习率0.001、温度0.07，并选择 α=0.1。原文消融文字报告监督基线 Recall94.88%，加监督对比后95.59%，完整组合97.51%；这些是其数据和划分下的结果，不是我们在1e-5工作点上的预期收益。原文也指出浅层指导过强会降低性能。

### 选择的部分及必要修改

本次借鉴 **Gini 引导的浅深特征对齐与监督对比尾部**，不替换 ADN 编码器。

- 接入位置：原 GAP 的512维向量之后。深层投影512→128→128。
- 现有实验只给单个 CUT 的 IQ512，因此不伪造参考距离单元，不把 RAA、RDPH 等“相对”特征改成除以任意常数后仍用原名。
- 改为10个单 CUT 描述量：幅度变异系数、归一化四阶矩、滞后1相关幅度、归一化 Doppler 熵、谱峰功率占比、谱平坦度、绝对频率质心、三级 Haar 的 WAER、细节熵、log(1+WFR)。全部只读取当前 IQ。
- Haar 对复数两路正交分量作正交变换，保留能量定义。原文未明确给出足以唯一复现的 wavelet family 和边界设置；Haar 是我们声明的适配选择。
- 特征标准化和 Gini 权重只在原 TRAIN30k 上拟合。采用式(6)的非负 Gini decrease 归一化，避免“低杂质更好”与直接归一化杂质值之间的方向歧义。
- 浅层投影10→64→128，使用 LayerNorm，避免单样本推理受到 batch 统计影响。
- 原文式(11)的分母文字描述为负样本求和；本次明确采用标准 SupCon 的“全部非自身样本”分母，不声称这是作者原样实现。
- 损失设为 CE+0.02×[0.1×双向对齐+0.9×SupCon]，温度0.07；本次双向对齐也使用该温度，原文式(10)没有显式温度参数。CE 主导，避免重复此前强尾部排序损失破坏判别边界的做法。
- 推理时将浅深128维向量拼接后产生有界分数修正；原文主要将浅层指导用于表征训练，本次保留推理端浅深残差融合，是我们额外声明的修改。
- 新增108,865个参数；原 TFSE、ADN 及原分类头仍全部冻结。没有原 L1-Tail、TFCG、DHiF、CGCR 或额外H0挖掘。

### 本路的研究假设

在固定深层特征上，补充训练集筛选过的单 CUT 物理描述量，并用对齐与对比约束训练小型尾部，可能改善原分类头对难例的排序。WFR 对原文低速目标有效，不代表对我们所有模拟目标都有效，Gini 权重和后续实验负责检验其适用性。

## 3. 两路共同的实验约束

原分数 d=z1-z0 保留。每路只学习 δ=0.5×s×tanh(r)，其中 s 是 TRAIN 原分数标准差，限制到[0.25,2]；新分数为 d+δ。修正头最后一层零初始化，初始完整函数等于冻结 A1。单独验证新增分支在4个优化步骤后确有非输出层参数更新。

默认使用现有完整 TRAIN30k/VAL5k，只缓存一次冻结特征，约1.14GiB。训练计算只涉及两路小型尾部。每路12个epoch，按 VAL FPR≤0.01的归一化pAUC优先、CE次优选择实际训练后的检查点。epoch0只作参照，不参与候选选择；即使训练后没进步，也保留真实结果，不以旧模型冒充新模型。

中规模评分：独立 CAL300k、AUDIT200k、每SCR512个H1、-24至+12dB共37点、标称Pfa1e-4。完整评分：CAL3M、AUDIT1M、每SCR1024个H1、相同37点，Pfa1e-4和1e-5。

基线只读取原 B280 A1 的历史原始分数。中规模使用配对前缀，并以同规模CAL重新确定阈值；其数字可能与历史3M阈值下不同，这不是基线重训练。完整规模使用原完整分数，不改写旧曲线。新尾部推理共享一次冻结骨干前向，不为基线再跑一遍网络。

所有权重和超参数选择仅使用 TRAIN/VAL。已多次查看的DEV用于探索性方案筛选；最终论文的泛化结论需要锁定方案后的独立TEST。报告中附H0审计Wilson区间、配对H1的D90差值与Pd@0增益区间；H1自助法固定CAL阈值，不包含阈值校准不确定性。

这两路都需要引用相应 TAES 原文。算法命名或组合本身不能证明创新性，也不能保证 Pd 提升；后续若有稳定收益，应再补充针对改造部分的消融，而不是省略来源。
